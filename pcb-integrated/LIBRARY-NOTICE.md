# Library provenance

Original project code, hardware designs and documentation are released under the root MIT LICENSE. Third-party library contributions retain their own licenses and exceptions.

The schematic embeds symbols from the installed KiCad standard libraries.
The project-local ESP32_S3_WROOM_1_Overhang footprint derives from KiCad's
RF_Module:ESP32-S3-WROOM-1 footprint; its front silkscreen graphics were removed
for antenna overhang, while pads, courtyard and RF keepout were retained.
KiCad library licensing and its exception continue to apply to those library contributions:
https://www.kicad.org/libraries/license/

USB_A_SameSky_UJ2_AH_SMT and L_Coilcraft_XGL4020 land patterns were authored
from the manufacturers' recommended dimensions. Pin-map references are listed
in README.md. Vendor datasheets are retained only in the ignored local references directory.
